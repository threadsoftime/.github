# Threads of Time

**An AI-driven _World of Warcraft: Wrath of the Lich King_ (3.3.5a) expansion, built on [AzerothCore](https://www.azerothcore.org/).**

Threads of Time turns a private WotLK realm into a living world:

- 🤖 **Alive bots** — LLM-orchestrated characters with persistent cross-session memory, personalities, and goal-directed behavior. They remember you, greet you by name, and play alongside you.
- 🪜 **Bracketed progression** — each major release masters one level bracket. **1.x = Bracket 1 (levels 1–25)**: complete, hand-tuned content you master rather than outgrow.
- ⚔️ **Custom content** — 54 spec-specific tier-set bonuses, a Blackfathom Deeps raid, and Legion-style Warforged + Bonus Socket procs on drops.

### Run your own realm

A single composed client patch plus a reference container stack (Podman Quadlet or Docker Compose), with a one-command installer. **Bring your own LLM** — point it at any OpenAI-compatible endpoint (Ollama, llama.cpp, or a hosted API). No GPU required on the server.

➡️ **[threads-of-time](https://github.com/threadsoftime/threads-of-time)** — source, releases, and operator docs.
